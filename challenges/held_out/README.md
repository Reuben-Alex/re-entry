# Live held-out challenges

Place teammate-written `.sol` files here for demo day. They are **gitignored** so the model never sees them in the repo.

1. Add `YourChallenge.sol` with contract name matching the manifest entry.
2. Add a row to `challenges/manifest.json` with `"tier": "held_out_live"`.
3. Run `bash scripts/held_out_demo.sh`.

Do not commit sources from this folder.
